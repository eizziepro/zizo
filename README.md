# Zizo Surrogacy Website

A calm, discreet, and ethically guided reproductive care coordination website for intended parents and surrogate applicants in Lagos, Nigeria.

## Architecture

- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript
- **Styling**: Vanilla CSS with custom properties matching the design system
- **Typography**: Inter & Newsreader
- **Audiences**:
  - Intended Parents
  - Prospective Surrogates
- **Key Conversion Channels**: Verified Direct WhatsApp & Consultation Scheduling

## Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Typecheck & Build**:
   ```bash
   npm run typecheck
   npm run build
   ```
